# RCP Student Wiki

Welcome to the RCP Student Wiki — the central place for RCP students to find degree plans, program policies, important files, and student resources.

## What's here

- **[Degree Plans](degree-plans/index.md)** — recommended course sequences and requirements by track/year
- **[Policies](policies/index.md)** — RCP program policies, deadlines, and procedures
- **[Important Files](important-files/index.md)** — forms, templates, and documents you'll need
- **[Student Resources](resources/index.md)** — advising, tutoring, funding, and other support resources

## Contributing

This wiki lives in the [RCPwiki repository](https://github.com/RCP-MINES/RCPwiki). To suggest an edit:

1. Click the pencil icon (✎) at the top of any page to edit it directly on GitHub, or
2. Clone the repo, edit the Markdown files under `docs/`, and open a pull request

See the repository [README](https://github.com/RCP-MINES/RCPwiki#readme) for local setup instructions.
